## Keybinds

*Super = Windows key; Return = Enter*

### General

- **Super + Space:** Change keymap

### Default Apps

- **Super + Return:** Open terminal
- **Super + R:** Open app launcher
- **Super + E:** Open file manager
- **Super + B:** Open web browser

### Session

- **Super + M:** Exit Hyprland
- **Super + L:** Lock session

### Window Management

- **Super + Shift + Q:** Close window
- **Super + Arrow keys:** Switch window focus
- **Super + F:** Toggle fullscreen
- **Super + V:** Toggle floating
- **Super + J:** Toggle split direction
- **Super + P:** Toggle window pseudo
- **Super + Alt + Arrow keys:** Resize window
- **Super + Left mouse button:** Drag floating window
- **Super + Right mouse button:** Resize floating window

### Workspace Management

- **Super + 1–0:** Switch workspace
- **Super + Mouse wheel up/down:** Switch workspace
- **Super + Shift + 1–0:** Move window to workspace
- **Super + S:** Open special workspace
- **Super + Shift + S:** Move window to special workspace

### Volume and Media Player

- Default keyboard buttons work

### Screenshots

- **Print Screen:** Take a region screenshot
- **Super + Print Screen:** Take a monitor screenshot

### Power Management

- **Super + Alt + R:** Reboot
- **Super + Alt + P:** Shut down
